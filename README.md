# 나인빅스 기도마당 — 차량 배치 수정 v5 전체본

이번 파일은 수정 도구가 아닌 전체 index.html입니다. 이전 파일은 필요 없습니다.

## 수정
- 차량 위치 (8.6, .12, 7.1) -> (3.8, .12, 9.0): 입구 쪽으로 이동
- 차량 보기 목표점을 car.position에서 계산해 좌표 불일치 방지
- 세로 화면 차량 보기 카메라 거리를 늘려 차량 전체를 담도록 조정
- 기본 카메라 시야 확대 및 오른쪽으로 중심 이동
- 남색 차량 보기 버튼 강조, 클릭 시 채팅창 접기
- 화면 하단에 '차량 배치 수정 v5' 표기

## 사용
GitHub 저장소의 index.html을 이번 파일로 완전히 교체해 Commit합니다.
최초 배포는 Settings > Pages > Deploy from a branch > main > / (root) > Save.
ZIP 자체를 올리지 말고 압축을 해제한 파일들을 저장소 루트에 올리세요.
배포 완료 뒤 페이지를 새로고침하세요. 하단 '차량 배치 수정 v5'를 확인하세요.
입장 후 파란색 '남색 차량 보기' 버튼으로 차량을 확인하세요.
이동 또는 시야 초기화로 캐릭터 시점으로 돌아갑니다.

## 유지 기능
흰 말티즈와 초록 야구 상의, 모자/흰색 앞판 없음, 방석 24개, 합장/앉기,
사찰풍 합성음악, 낮/노을/밤, 이름 입장, 멀티플레이어, 채팅, 5초 말풍선,
우승 기원 문구 15개 자동 선택 버튼, 남색 모델 Y 참고 소품과 주차선.
차량은 공식/정밀 CAD 모델이 아닌 단순화된 창작 소품입니다.
마당은 실제 감독님 주택이나 로드뷰를 복제한 것이 아닙니다.

## 조작
WASD/방향키 이동, 드래그 시야, 1 합장, 2 방석 앉기, 3 인사, 4 응원,
Enter 채팅, Esc 입력 해제. 모바일은 조이스틱/버튼.
같은 room 이름의 초대 링크로 모입니다. 통신 채널은 v4로 이전 말풍선 버전과 호환됩니다.
차량 위치가 일치하려면 모두 이 파일로 갱신해야 합니다.

## 제한
인터넷/WebGL과 외부 Three.js/MQTT.js CDN이 필요합니다.
멀티플레이어/채팅은 공개 EMQX MQTT 테스트 서버에 의존합니다.
비공개/인증/성능/지속 운영을 보장하지 않습니다. 이름/위치/메시지가 공개 채널에 전송됩니다.
앱에 대화 저장 기능은 없지만 외부 서버의 수집/보관 여부를 보장하지 않습니다.
개인정보를 입력하지 마세요. 정식 팀 전용 운영은 전용 서버/인증/접근 제어가 필요합니다.
파일 및 코드의 정적 검사는 수행했지만 실제 브라우저 렌더링/다중 기기 테스트는 하지 않았습니다.
