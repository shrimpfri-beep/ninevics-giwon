# 나인빅스 팀원들의 기도 — 차량 포함 전체 통합본

별도의 수정 도구나 이전 HTML은 필요하지 않습니다.
index.html 한 파일에 전체 앱이 들어 있습니다. 인터넷은 필요합니다.

## 기존 GitHub Pages 업데이트
1. index.html을 이번 파일로 완전히 교체합니다.
2. Commit changes 후 배포 완료를 기다립니다.
3. 사이트를 새로고침합니다. 모든 참가자가 최신 파일로 접속해야 합니다.

## 처음 배포
ZIP을 압축 해제한 뒤 index.html, README.md, .nojekyll을 저장소 루트에 올리세요.
ZIP 자체를 업로드하지 마세요.
Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
Pages 설정에 표시되는 실제 사이트 주소로 접속합니다.

## 포함 기능
흰색 말티즈 + 자연스러운 초록색 야구 상의, 모자/흰색 앞판 없음.
나인빅스 팀원들의 기도 / 용인·감독님 집 앞마당.
나인빅스 밀양 우승 기원 현수막, 방석 24개, 앉기와 합장 동시 사용.
이름/별명 입장, 같은 방 멀티플레이어, 채팅, 5초 말풍선,
우승 응원 문구 15개 자동 선택 버튼, 사찰풍 창작 합성음악, 낮/노을/밤.
오른쪽 마당에 남색 모델 Y 참고 차량과 주차선. 차량 보기 버튼 포함.
차량은 정밀/공식 CAD가 아닌 단순화된 창작 소품이며 운전/문열기는 없습니다.
실제 주택/로드뷰 재현이 아닌 창작 마당입니다.

## 조작
WASD/방향키: 이동, 드래그: 시야, 1: 합장, 2: 빈 방석 앉기, 3: 인사,
4: 우승 응원, Enter: 채팅, Esc: 입력 해제. 모바일은 조이스틱과 버튼.
'차량 보기'로 차량을 확인하고 이동 또는 '시야 초기화'로 돌아갑니다.
같은 room 값을 가진 초대 링크로 모이세요.

## 통신/보안/검증 한계
GitHub Pages는 정적 호스팅이며 통신은 별도 공개 EMQX 테스트 MQTT 서버
(wss://broker.emqx.io:8084/mqtt)에 의존합니다.
공개 서버의 안정성/운영 지속/성능은 보장하지 않습니다.
이름/위치/대화는 공개 채널로 전송되며 비공개/인증 기능이 없습니다.
앱에는 대화 이력 저장 기능이 없지만 외부 서버의 수집/보관 여부는 보장하지 않습니다.
개인정보를 입력하지 말고 별명을 사용하세요.
실시간 채널은 v4이며 이전 v3 버전과 통신하지 않습니다.
클라이언트 측 메시지 제한은 보안 장치가 아닙니다.
캐릭터 수 제한은 다른 이용자 31명이나 동시접속 성능은 검증하지 않았습니다.
외부 Three.js/MQTT.js CDN과 인터넷/WebGL이 필요합니다.
파일 구조/코드 정적 점검만 수행하며 실제 브라우저/모바일/다중기기 테스트는 하지 않았습니다.
정식 팀 전용 운영에는 전용 실시간 서버/인증/접근 제어가 필요합니다.

## 안 될 때
입장 버튼이 '3D 공간 준비 중'에서 멈추면 인터넷/CDN/WebGL을 확인하세요.
실행 오류가 화면에 표시되면 캡처해 공유하세요.
'서버 연결 중'만 남으면 테스트 서버 또는 네트워크 문제일 수 있습니다.
음악은 입장 동작 후 재생되며 음악 버튼/기기 음량을 확인하세요.
