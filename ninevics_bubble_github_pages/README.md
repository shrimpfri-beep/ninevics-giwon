# 나인빅스 기도마당 — 말풍선 버전

## 업데이트
- 채팅을 보내면 해당 캐릭터 머리 위 말풍선에 5초간 표시됩니다.
- 긴 문구는 말풍선에서 줄임표로 표시되며 채팅창에는 최대 200자 전체가 남습니다.
- 새 메시지는 기존 말풍선을 교체합니다. 마지막 0.5초는 흐려집니다.
- 4번 키 또는 '우승 기원 한마디' 버튼은 준비된 문구 15개 중 하나를 선택해 보냅니다.
- 응원 버튼은 접속 중인 같은 방 이용자에게 채팅과 말풍선으로 공유합니다.
- 오프라인이면 응원 버튼만 본인 화면에서 미리보기로 작동합니다. 미전송을 안내합니다.
- 전송 최소 간격 1.2초. 자동으로 주기 전송하는 기능은 없습니다.

## GitHub Pages
기존 저장소의 index.html을 이 파일로 교체하고 Commit changes를 누르세요.
최초 배포: Settings > Pages > Source: Deploy from a branch > main > / (root) > Save.
ZIP 자체를 업로드하지 말고 압축 해제한 index.html, README.md, .nojekyll을 루트에 올리세요.
배포 완료 후 Pages 화면의 실제 주소로 접속하세요.
모든 참가자가 새 버전을 새로고침해야 합니다. 이번 버전은 v4 통신 채널을 사용하므로
이전 v3 버전과 서로 보이지 않습니다.

## 조작
WASD/방향키: 이동 / 드래그: 시야 / 1: 합장 / 2: 방석 앉기 / 3: 인사
4: 우승 응원 / Enter: 채팅 / Esc: 채팅 포커스 해제
앉은 채 합장 가능합니다. 초대 링크로 같은 room 값을 공유하세요.

## 문구 바꾸기
index.html의 CHEERS 배열 안의 문장을 수정하세요.

## 기능과 주의
흰색 말티즈, 초록 야구 상의(모자와 흰색 앞판 없음), 방석 24개, 공동 기도,
사찰풍 창작 합성음악, 낮/노을/밤, 멀티플레이어, 채팅.
실제 로드뷰나 주택을 복제한 배경이 아닌 창작 앞마당입니다.
인터넷/WebGL이 필요하며 Three.js/MQTT.js를 외부 CDN에서 읽습니다.
GitHub Pages는 정적 파일 호스팅이고 실시간 통신은 별도의 공개 EMQX 테스트
서버 wss://broker.emqx.io:8084/mqtt 에 의존합니다. 인증과 비공개 접근 제어가
없으며 접속/성능 보장이 없습니다. 이름, 위치, 대화는 공개 채널로 전송됩니다.
앱에는 이력 저장 기능이 없지만 외부 서버의 수집 및 보관 여부는 보장하지 않습니다.
실명을 피하고 개인정보를 전송하지 마세요. 클라이언트 측 제한은 보안 기능이 아닙니다.
본격적인 팀 전용 운영에는 전용 서버/인증/접근 제어가 필요합니다.
다른 캐릭터 표시는 최대 31명으로 제한했으나 동시접속 성능은 검증하지 않았습니다.
실제 브라우저/기기 간 동기화/말풍선/음악은 아직 실행 테스트하지 않았습니다.
