남색 모델 Y 차량 추가 패키지

이 파일은 전체 사이트 대체본이 아닌 기존 HTML을 수정하는 도구입니다.
1. add_navy_model_y.html을 브라우저에서 엽니다.
2. 직전 말풍선 버전 index.html을 선택합니다.
3. 차량을 추가한 HTML 저장을 눌러 수정된 index.html을 저장합니다.
4. 수정된 파일로 GitHub 저장소의 index.html을 교체합니다.
원본 파일은 브라우저 내부에서만 처리되며 업로드하지 않습니다.

남색 차체, SUV 실루엣, 유리 지붕, 창문, 바퀴, 조명과 소형 T형 엠블럼.

차량은 배경 소품이며 운전, 문 열기, 새 충돌 판정은 포함하지 않습니다.
기존 음악/방석/기도/채팅/말풍선 코드를 그대로 둡니다.
각 접속자가 갱신된 HTML을 열면 같은 위치에 차량이 표시됩니다.
차량 추가/수정 도구는 파일 생성만 확인했으며 실제 브라우저 테스트는 하지 않았습니다.
